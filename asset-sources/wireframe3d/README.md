# Wireframe 3D Asset Sources

This directory stores source material generated by the local wireframe 3D tool. These files are not game runtime assets. They are working inputs for composing, checking, and producing final artwork.

## Layout

- `commands/`: parameterized command batches for `tools/wireframe3d-cli.js`.
- `scenes/`: generated scene JSON snapshots.
- `svg/`: generated SVG previews and debug exports.

The command payload schema lives at `docs/wireframe3d-command.schema.json`.
