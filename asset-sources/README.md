# Asset Sources

This directory stores non-runtime source material used to produce final game assets.

- `comfyui/`: ComfyUI workflows, API payloads, run configs, and notes for image generation.
- `fonts/`: font source files and comparison specimens for runtime typography decisions.
- `wireframe3d/`: command batches, generated scene snapshots, and SVG previews from the local wireframe tool.

Final asset choices are documented in `../docs/ASSET_DECISIONS.md`.
